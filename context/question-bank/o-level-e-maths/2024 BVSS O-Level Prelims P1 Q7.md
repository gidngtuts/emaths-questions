## Question

> **Marks:** 3
> **Page:** 5

(a) Write down the set represented by the shaded region. [1]

![Venn diagram: universal set with circles A and B; the intersection and the region outside both circles are shaded](../../subjects/o-level-e-maths/past-year-papers/2024/BVSS/images/BVSS-2024-Prelim-EM-Paper-1-pages/page-05.png)

(b) It is given that $\xi = \{x : x\text{ is an integer}\}$, $A = \{x : x\leq 9\}$ and $B = \{2, 4, 6, 8\}$.

State and explain whether the following mathematical statements are true or false.

(i) $B\subset A$. [1]

(ii) $B\in A$. [1]

## Answer Scheme

(a) $(A\cap B)\cup (A\cup B)'$. B1.

(b) (i) True, because all the elements in $B$ are in $A$ and $B\neq A$. B1.

(ii) False, because $B$ is a set, not an element. B1.
