## Question

> **Marks:** 13


> **Page:** 4–5

(a) (i) Solve the inequalities $-9 < 5 - 4x \le 6$. [2]

(ii) Write down all the integers that satisfy $-9 < 5 - 4x \le 6$. [1]

(b)

$$y = \frac{5 - x^2}{x^2 + w}$$

(i) Evaluate the value of $y$ when $x = 2.41$ and $w = 1.908$. Write your answer correct to three decimal places. [2]

(ii) Rearrange the formula to make $x$ the subject. [4]

(c) Solve

$$\frac{6}{x - 1} - \frac{4 - x}{3 - x} = 1.$$

[4]

## Answer Scheme

(a) (i)

$$-9 < 5 - 4x \le 6$$

$$-14 < -4x \le 1$$

$$-\frac{1}{4} \le x < 3\frac{1}{2}$$

(ii) Integers $x = 0, 1, 2, 3$.

(b) (i)

$$y = \frac{5 - (2.41)^2}{(2.41)^2 + 1.908} = \frac{-0.8081}{7.7161} = -0.105$$

(ii)

$$y(x^2 + w) = 5 - x^2$$

$$x^2(y + 1) = 5 - yw$$

$$x = \pm \sqrt{\frac{5 - yw}{y + 1}}$$

(c)

$$\frac{6}{x - 1} - \frac{4 - x}{3 - x} = 1$$

$$2x^2 - 15x + 25 = 0$$

$$(2x - 5)(x - 5) = 0$$

$$x = 2\frac{1}{2} \text{ or } x = 5$$

The scheme also accepts a correct substitution into the general formula.
