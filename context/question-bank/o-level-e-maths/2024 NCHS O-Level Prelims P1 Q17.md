## Question

> **Marks:** (a) [3]; (b)(i) [2]; (b)(ii) [2]
> **Page:** 14

Given that

$\varepsilon = \{\text{positive integers less than } 17\}$,

$X = \{2, 3, 4\}$

$Y = \{\text{prime numbers}\}$

$Z = \{2, 3, 4, 5, \ldots, n-1, n\}$

**(a)** Draw a Venn Diagram to represent the set $\varepsilon$, $X$ and $Y$, indicating the elements clearly.

**(b)** **(i)** List all subsets of $X$.

**(ii)** Hence, deduce the number of subsets of $Z$ in term of $n$.

## Answer Scheme

**(a)** $X\cap Y = \{2, 3\}$, $X$ only $= \{4\}$, $Y$ only $= \{5, 7, 11, 13\}$, and outside both $= \{1, 6, 8, 9, 10, 12, 14, 15, 16\}$.

![Venn diagram for Q17](../../subjects/o-level-e-maths/past-year-papers/2024/NCHS/images/2024-NCHS-Prelim-Math-P1-Suggested-Solutions-pages/page-05.png)

**(b) (i)** $\varnothing$ or $\{\}$, $\{2\}$, $\{3\}$, $\{4\}$, $\{2, 3\}$, $\{2, 4\}$, $\{3, 4\}$, $\{2, 3, 4\}$

**(ii)** Number of subsets $= 2^{n-1}$
