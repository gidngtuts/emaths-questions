## Question

> **Marks:** (a) 1, (b) 2, (c) 7; total 10
> **Page:** 20–22

An event organiser is organising a 3-day Pet Festival for 300 exhibitors. The event organiser charges each exhibitor a registration fee of ＄90 and a daily booth rental of ＄150.

**(a)** Calculate the total amount of money the organiser collected from each exhibitor. [1]

The event organiser needs to rent an exhibition space for the Pet Festival. The spaces required for the exhibition are as follows:

|  |  |
| --- | --- |
| Each booth size | $15\text{ m}^{2}$ |
| Aisle space for visitors and open spaces required | 65% of the total area occupied by the booths |

The layout, size and rental fees for the exhibition halls are as follows:

| Hall A | Hall B | Hall C |
| --- | --- | --- |
| $3000\text{ m}^{2}$ | $3500\text{ m}^{2}$ | $4000\text{ m}^{2}$ |
| ＄5000 per day | ＄6000 per day | ＄8000 per day |

| Hall D | Hall E |
| --- | --- |
| $3900\text{ m}^{2}$ | $3600\text{ m}^{2}$ |
| ＄8200 per day | ＄5400 per day |

Adjacent halls have foldable partitions that can be opened up for rental of two halls. Rental is for one entire hall space.

**(b)** Calculate the minimum amount payable by the event organiser for the daily rental of the exhibition hall(s) needed. [2]

In order to set up the exhibition, the event organiser needs to rent the hall(s) and the items needed one day before the start of the 3-day Pet Festival.

| Location | Items | Rental fees |
| --- | --- | --- |
| Each booth | 1 long table | Long table: ＄2 each table per day |
|  | 2 square tables | Square table: every 100 tables at ＄30 per day |
|  | 4 chairs | Round table: every 5 tables at ＄20 per day |
| Open space | 75 round tables | Chairs: every 50 chairs at ＄10 per day |
|  | 300 chairs |  |

For the 3 days of exhibition, the event organiser will employ 2 security guards and 4 part-timers for 12 hours for each day of the exhibition.

- ＄10 per hour for each security guard
- ＄8 per hour for each part-timer

**(c)** It is estimated that there will be a total of 35 000 visitors for the 3-day exhibition.

The event organiser says: we will meet our minimum target profit of ＄300 000 if we charge an entrance fee of ＄6 per visitor.

Is the event organiser correct? Using your answers in part (a) and (b), justify your decision with calculations. [7]

## Answer Scheme

**(a)** $90+3\times 150 = 540$. ＄540. B1.

**(b)** Size of hall required $= (300\times 15)\times 1.65 = 7425\text{ m}^{2}$.

Hall C and Hall E (total area $7600\text{ m}^{2}$). Daily rental $= 8000+5400 = 13400$. ＄13400. M1, A1.

**(c)** Hall rental $= 13400\times 4 = 53600$.

Long tables $= 300\times 2\times 4 = 2400$.

Square tables $= \dfrac{600}{100}\times 30\times 4 = 720$.

Round tables $= \dfrac{75}{5}\times 20\times 4 = 1200$.

Chairs: $300\times 4+300 = 1500$, so $\dfrac{1500}{50}\times 10\times 4 = 1200$.

Security guards $= 2\times 10\times 12\times 3 = 720$.

Part-timers $= 4\times 8\times 12\times 3 = 1152$.

Total cost $= 53600+2400+720+1200+1200+720+1152 = 60992$.

Amount collected from exhibitors $= 300\times 540 = 162000$.

Entrance fees $= 35000\times 6 = 210000$.

Profit $= 162000+210000-60992 = 311008$.

The profit of ＄311008 is more than the minimum target of ＄300000. The event organiser is correct.

5 items: M3. 4 items: M2. 2 items: M1. Either staff cost: M1. Exhibitor income: M1. Profit: M1. Comparison: A1.
