# E-Maths Questions

A copy of the existing Tuition OS O-Level E-Maths Markdown notes and images, prepared on 13 October 2026. Original vault files remain unchanged.

- 1,595 individual question notes: `context/question-bank/o-level-e-maths/`
- Cleaned papers, mark schemes and page images: `context/subjects/o-level-e-maths/past-year-papers/`
- Learning objectives, notes and syllabus text: `context/subjects/o-level-e-maths/`
- Syllabus overview: `context/subjects/syllabus/O Level E Maths.md`

Only Markdown and image files are included. PDFs, Word documents, ZIP archives and Obsidian Base/JSON files are excluded.

Image embeds use relative paths. The source folder structure is preserved, so images remain available when browsing the Markdown files or cloning the repository. Keep the folders together; moving a note alone can break its image paths. Obsidian wikilinks between notes retain their original syntax and are intended for Obsidian.

This is a snapshot; later changes in Tuition OS are not automatically synchronized. The syllabus overview retains historical references to external vaults and a PDF that is excluded from this copy.
